#Assignment 1 - Builder Pattern

## How to Run

### Requirements
- JDK 17 or higher

### Clone the repository
```bash
git clone https://github.com/pParalich/sdp_assignment1.git
cd sdp_assignment1
```

### Run via IntelliJ IDEA
1. Open the project folder in IntelliJ IDEA.
2. Locate `src/Main.java`.
3. Click the run icon next to the `main` method.

### Run via command line
```bash
cd src
javac *.java
java Main
```
